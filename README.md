# ⚡ Restream Rust Engine

Ultra-Low RAM Stream HUD & RTMP Fan-out Relay in Native Rust (Zero-GC).

## 🚀 Especificações
* **Runtime:** Native Rust 2021 (Zero-GC, RAII)
* **Memória:** < 20MB RAM física total
* **Portas:**
  * Ingest RTMP: `1935`
  * Web Dashboard / Telemetria: `3008`
* **Destinos:**
  * Kick RTMP
  * Twitch RTMP
  * YouTube RTMP
* **Pipeline de Áudio:** Nightwave Plaza Lo-Fi (`https://radio.plaza.one/mp3`)
